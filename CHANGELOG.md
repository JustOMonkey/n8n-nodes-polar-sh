#### [1.1.0](https://github.com/JustOMonkey/n8n-nodes-polar-sh/compare/1.0.2...1.1.0)

> 25 September 2026

Aligns the package with Polar's versioned API (2026-10 OpenAPI spec) and adds a second node for the Customer Portal API.

**New: Polar Customer Portal node** — acts on behalf of one customer with a short-lived customer/member session token (from Polar → Customer Session → Create). Covers all 47 `/customer-portal` endpoints: Benefit Grant, Customer, Customer Meter, Downloadable, License Key, Member, Order, Organization, Payment Method, Seat, Session, Subscription, Wallet. [`895b0a5`](https://github.com/JustOMonkey/n8n-nodes-polar-sh/commit/895b0a50e2c5891bf381ccd10aa0c73e3e53226d)

**Polar node**

- New resources: Metric (Get, Export, Get Limits), Metric Dashboard (CRUD), Organization (Get, Get Many, Update) [`c22c82c`](https://github.com/JustOMonkey/n8n-nodes-polar-sh/commit/c22c82c1d98fbf79b776e3e521b2135ef7969baf) [`96dbd50`](https://github.com/JustOMonkey/n8n-nodes-polar-sh/commit/96dbd50)
- New operations: Customer / Order / Subscription Export (CSV as a binary file), Customer Get Payment Methods by External ID, Dispute Accept, License Key Rotate, Product Delete, Benefit Get Files [`0eb831d`](https://github.com/JustOMonkey/n8n-nodes-polar-sh/commit/0eb831d) [`f3a5cf4`](https://github.com/JustOMonkey/n8n-nodes-polar-sh/commit/f3a5cf4)
- Member now uses Polar's customer-scoped endpoints (`/customers/{id}/members`), with "External" variants; Customer ID is now required [`3e05d3a`](https://github.com/JustOMonkey/n8n-nodes-polar-sh/commit/3e05d3a)
- Removed the Organization Access Token resource — Polar no longer exposes these endpoints [`576c590`](https://github.com/JustOMonkey/n8n-nodes-polar-sh/commit/576c590)
- Export date filters are sent with a UTC offset, as Polar requires [`69c8251`](https://github.com/JustOMonkey/n8n-nodes-polar-sh/commit/69c8251)

**Polar Trigger**

- 7 missing webhook events: `subscription.cycled`, `subscription.paused`, `subscription.resumed`, `subscription.migrated`, `discount.created`, `discount.updated`, `discount.deleted` (42 total) [`b662c3d`](https://github.com/JustOMonkey/n8n-nodes-polar-sh/commit/b662c3d)

**Maintenance**

- OpenAPI audit script (`scripts/audit-openapi.mjs`) and a `node:test` suite, now run in CI
- chore(deps-dev): bump @n8n/node-cli to 0.46.1 [`#7`](https://github.com/JustOMonkey/n8n-nodes-polar-sh/pull/7) [`#9`](https://github.com/JustOMonkey/n8n-nodes-polar-sh/pull/9)

See the README's "Upgrading to 1.1" notes for Member and Organization Access Token changes.
